# Imagery

Every image in this folder is generated, not photographed, and not taken from a
stock library: `scripts/` renders them onto a canvas from code (floodlights,
crowd bokeh, mown turf, hoardings) and saves the result as a JPEG. There is no
third-party material here and nothing to attribute.

- `stadium-night.jpg` — a ground under lights, from a corner. Landing hero.
- `crowd.jpg` — an out-of-focus crowd band. Behind the live scoreboard.
- `turf.jpg` — mown grass. The tactics pitch and small headers.

To swap in real photographs, drop files with these names into this folder. Use
a licence that allows it (Unsplash and Pexels both permit commercial use without
attribution) and keep each file under about 300 kB.
